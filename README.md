# TrustFed-6G / TrustFed AI
Adaptive Trust- and Privacy-Aware Federated Learning for Resource-Efficient 6G Edge Networks.

## Core research
UNSW-NB15 + MLP/DNN + Flower FL + virtual heterogeneous IoT clients + Differential Privacy + TPRS + trust-aware aggregation + controlled poisoning.

## TPRS
TPRS combines:
Trust + Data/Update Quality + Resource Availability + Network Quality - Privacy Risk.

TPRS controls:
1. client selection
2. adaptive privacy
3. aggregation influence

## Software-only 6G
No physical IoT hardware or sensors are required. CPU, energy, bandwidth and latency are simulated.
